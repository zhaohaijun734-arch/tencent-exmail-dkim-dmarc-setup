# tencent-exmail-dkim-dmarc-setup

End-to-end setup of DKIM + DMARC for Tencent Exmail (企业邮箱) domains whose
DNS is hosted on DNSPod - including the non-obvious console entries, SPF
alignment, mail-tester verification, and the rollout order that avoids
rejecting your own mail.

Ships as an agent SKILL.md: install by copying `SKILL.md` into your agent's
skills directory.
